# 가입 링크 다시 보기 (010)

009 단원 가입 설정을 적용한 뒤, 010_saved_member_links.sql 전체를 Supabase SQL Editor 새 쿼리에 붙여 넣고 Run을 누르세요.
성공 결과: ChoirON saved member links ready

관리자 화면 → 단원·일정 관리 → 합창단 선택 → 단원 탭에서 해당 합창단의 최근 가입 링크를 자동으로 불러옵니다. 화면을 닫거나 다른 기기에서 로그인해도 다시 확인·복사할 수 있습니다.
합창단 관리자 역할 단원도 내 정보 → 이 합창단 단원 초대에서 확인합니다.

- 표시: 가입 링크, 사용 가능·만료·취소 상태, 만료 일시, 가입한 인원
- 새 가입 링크 만들기: 기존 사용 중인 링크를 교체할지 확인 후 생성
- 가입 링크 취소: 새 가입을 막으며 기존 단원은 유지
- 기존 사용 조건인 7일·최대 500명은 그대로 유지

이전 방식은 링크의 원문을 저장하지 않았으므로 이미 닫은 링크의 원문은 복구할 수 없습니다. 저장 설정 적용 후 새 링크를 한 번 만들어 주세요. 이전 링크가 자동으로 취소되는 것은 아니며, 새 링크를 만들 때 교체됩니다.
저장된 링크 조회는 해당 Workspace 또는 합창단 관리자에게만 허용됩니다.
