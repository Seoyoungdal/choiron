# 단원 직접 가입 설정

기존 008 설정까지 적용한 프로젝트에서 009_member_enrollment.sql 전체를 Supabase SQL Editor의 새 쿼리에 붙여 넣고 Run을 누르세요.
결과: ChoirON member enrollment ready

1. 관리자 화면 → 내 Workspace 관리 → 합창단 선택 → 단원 탭 → 가입 링크 만들기 → 가입 링크 복사.
2. 카카오톡·문자 등으로 단원에게 직접 보내 주세요.
3. 단원은 링크를 열어 교회·합창단 이름을 확인한 후 이름, 한글 아이디, 숫자 6~12자리 PIN, 파트를 입력합니다. 이메일 인증은 없습니다.
4. 같은 Workspace의 기존 단원은 ‘기존 계정으로 참여’를 선택합니다. 기존 PIN과 다른 소속은 유지됩니다. 다른 Workspace는 각각 가입하고 앱에서 각각 로그인하면 일정을 함께 볼 수 있습니다.
5. 일반 단원 로그인 화면에도 ‘회원가입 · 가입 링크 입력’이 있습니다. 관리자의 가입 링크가 있어야 가입할 수 있습니다.

합창단 관리자 역할을 가진 단원도 내 정보 → 이 합창단 단원 초대에서 링크를 만들 수 있습니다.
링크는 7일·최대 500명입니다. 새로 만들면 이전 링크가 취소됩니다. 링크 취소는 이미 가입한 단원을 삭제하지 않습니다. 다시 보내려면 복사해 둔 링크를 보내거나 새 링크를 만들어 주세요.

이번 변경은 단원 PIN 계정 가입입니다. 관리자 이메일 로그인·메일 인증 설정은 별도입니다.
