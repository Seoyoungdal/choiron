# 홈 화면 아이콘

관리자 화면은 보라색 ChoirON, 단원 화면은 파란색 ChoirON 기본 아이콘을 사용합니다. 앱 이름도 ChoirON 관리자 / ChoirON 단원으로 구분합니다.

관리자 → 내 Workspace → 디자인 설정 → Workspace 로고 · 앱 아이콘 등록 → 이미지 선택 → 적용.
등록한 로고는 웹 화면과 앱 설치 아이콘에 함께 사용합니다. 기본 아이콘 사용 → 적용으로 되돌릴 수 있습니다.

관리자·단원 화면 아래 ‘앱 설치 · 홈 화면에 추가’에서 설치합니다. 자동 설치 창을 지원하지 않으면 기기에 맞는 안내가 나옵니다. iPhone은 Safari 공유 → 홈 화면에 추가를 이용하세요.

각 기기에서 해당 Workspace에 로그인한 뒤 설치하면 저장된 로고가 준비됩니다. 여러 Workspace를 사용하는 경우 마지막으로 선택한 Workspace의 로고를 사용하며 역할별 앱은 각각 하나입니다. 이미 설치된 아이콘은 기기에 따라 기존 홈 화면 아이콘 삭제 후 재추가가 필요합니다.

설치 정보와 공개 로고만 기기에 보관합니다. 회원 정보·출결·인증 토큰은 설치용 캐시에 저장하지 않습니다. 로그인과 출결에는 인터넷 연결이 필요합니다.
추가 Supabase SQL은 필요하지 않습니다.

검증: Chromium의 실제 앱 설치 정보 읽기로 관리자/단원 분리, 192/512 PNG, 사용자 아이콘 새로고침 후 유지, 기본 아이콘 복원과 안내 동작을 확인했습니다. 실제 iPhone 홈 화면 설치는 별도 기기 확인이 필요합니다.
